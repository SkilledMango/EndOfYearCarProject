מפת הפרויקט — תרגום ותמצית קצרה לפי תחומים

1. צד שרת (Backend) — ASP.NET Core 10 & SQL Server
הגדרות והרצה (CarStats.API/)

Program.cs: נקודת הכניסה של השרת; מגדיר חיבורי DB, אימות JWT, מנגנון הרשאות, מיגרציות אוטומטיות וטעינת נתונים ראשונית.

CarStats.API.csproj: קובץ הגדרות הפרויקט (.NET 10) והתלויות החיצוניות (BCrypt, EF Core, Swagger).

appsettings.json / appsettings.Development.json: קובצי קונפיגורציה למחירי דלק, לוגים ומחרוזות התחברות בסביבת פיתוח (ללא סודות).

Properties/launchSettings.json: הגדרות פורטים להרצה מקומית (5279 / 7077).

FTPProfile.pubxml: פרופיל פרסום ב-FTP לשרת ה-Production ב-Somee.

dotnet-tools.json / CarStats.API.http: כלי עזר מקומיים למיגרציות ולשליחת בקשות בדיקה ללא Postman.

שכבת נתונים ומודלים (Data/, Models/, Migrations/)

AppDbContext.cs: ניהול החיבור ל-SQL Server, הגדרת הטבלאות וחוקי מחיקה (למשל שמירת היסטוריית תקלות בעת מחיקת רכב).

DbSeeder.cs + DtcCatalog.cs: טעינת מילון קודי התקלות הסטנדרטיים (SAE J2012) כולל הסברים וטווחי עלויות בשקלים.

AppUser.cs: טבלת משתמשים, סיסמאות מוצפנות (BCrypt), תפקידים (User/Admin) וקודי אימות במייל.

Vehicle.cs: טבלת רכבים הכוללת פרטי יצרן, דגם, שנת ייצור ונתוני צריכת דלק ממוצעת.

VehicleEvent.cs: תיעוד תקלות בזמן אמת, זמני דיגום ושיוך לרכב ולמשתמש.

DiagnosticCode.cs: מילון התקלות, פירוש חומרתן (ירוק/צהוב/אדום) ופעולות לתיקון.

Migrations/: היסטוריית שינויי סכמת בסיס הנתונים של EF Core.

לוגיקה ושירותים (Services/)

TokenService.cs: הנפקת טוקנים מאובטחים (JWT) ל-30 יום לצורך אימות המשתמשים.

BrevoEmailService.cs (IEmailService.cs): שליחת קודי אימות במייל דרך API של Brevo (במקום SMTP החסום ברשתות רבות).

PasswordPolicy.cs: בדיקת חוזק סיסמה (מינימום 8 תווים, אותיות וספרות) המשותפת לכל דרכי ההרשמה.

CallerExtensions.cs: בדיקת הרשאות פנימית (CanActFor) שמוודאת שמשתמש ניגש אך ורק למידע של הרכב שלו, אלא אם הוא מנהל.

נקודות קצה (Controllers/)

AuthController.cs: הרשמה, אימות במייל והתחברות למערכת.

UsersController.cs: צפייה ועדכון פרופיל, ניהול משתמשים ומדידת כמות תקלות מחושבת.

VehiclesController.cs: הוספה, עדכון ומחיקת רכבים לפי הרשאות משתמש.

MobileController.cs: דיווח תקלות בזמן אמת (כולל מניעת כפילויות) והצגת היסטוריית אירועים מלאה.

DtcController.cs: שליפת מילון התקלות לאפליקציה ועדכונו על ידי מנהלים.

NavigationController.cs: שרת תיווך מול Google Maps (למציאת מוסכים וחישוב מסלולים) שמונע חשיפת מפתחות API ובעיות CORS.

FuelPriceController.cs: שליפת מחירי הדלק הרשמיים המעודכנים.

StatsController.cs: עיבוד נתונים וסטטיסטיקות עבור דאשבורד המנהלים.

2. אפליקציה ניידת (Mobile) — React Native / Expo
ליבה וניווט (app/, index.js)

index.js + app/_layout.tsx: אתחול האפליקציה, עטיפה בספקי עיצוב ואימות, רישום שירותי התראות וחסימת נתיבים למי שאינו מחובר.

app/(tabs)/_layout.tsx: הגדרת סרגל הטאבים התחתון.

app/(tabs)/index.tsx: המסך הראשי — התחברות למתאם ה-OBD, קריאת מדדים חיים וביצוע סריקת תקלות.

app/(tabs)/explore.tsx: היסטוריית תקלות העבר של הרכב.

app/(tabs)/fuel.tsx: מעקב צריכת דלק, תיעוד תדלוקים וחישוב הוצאות.

app/(tabs)/navigate.tsx: מפת מוסכים קרובים מבוססת מיקום עם אפשרות חיוג וניווט.

app/(tabs)/profile.tsx: ניהול פרטי משתמש, רכבים בחשבון והתנתקות.

app/login.tsx + app/register.tsx: מסכי כניסה והרשמה תלת-שלבית (פרטים, אימות קוד, הוספת רכב).

app/settings.tsx: הגדרות תצוגה (מצב כהה/בהיר), התראות והגדרת מיקום "בית" לבטיחות ילדים.

app/trip-planner.tsx: תכנון מסלול, בדיקת עומסי תנועה והערכה האם מפלס הדלק מספיק ליעד.

app/fault/[code].tsx: דף פירוט תקלה, דרכי פעולה והערכת עלות תיקון.

רכיבים ושירותים (components/, services/, utils/)

AddVehicleModal.tsx: זיהוי והוספת רכב לפי לוחית רישוי (מול מאגר ממשלתי) או הזנה ידנית.

ScanOverlay.tsx / LiveGauges.tsx / DtcResultCard.tsx: רכיבי ממשק לסריקה חיה, שעוני מדדים (סל"ד, מהירות, חום מנוע) וכרטיסיות תקלות לפי צבע חומרה.

ShopMap.tsx: מפת מוסכים מותאמת לסלולר ולסביבת ווב.

context/AuthContext.tsx + ThemeContext.tsx: ניהול המשתמש המחובר (כולל שמירה במכשיר) וניהול ערכות צבעים.

scanner.ts / demoScanner.ts: תקשורת מול ה-ESP32 בכתובת IP קבועה, לצד מצב דמו המאפשר הדגמה ללא רכב מחובר.

dtcLookup.ts: שימוש ב-Gemini להסבר תקלות שאינן מופיעות במילון הסטנדרטי.

vehiclelookup.ts / fueleconomy.ts: משיכת נתוני רכב לפי לוחית (data.gov.il) ונתוני צריכת דלק רשמיים (EPA).

notifications.ts: התראות מערכת והפעלת גדר גיאוגרפית (Geofencing) לשכחת ילדים ברכב בחסכון בסוללה.

utils/: פונקציות מתמטיות טהורות לחישובי דלק (fuel.ts), חומרת תקלות (severity.ts) ואימות סיסמאות (password.ts).

__tests__/: 82 בדיקות יחידה (Unit Tests) שמכסות את כלל הלוגיקה החישובית.

3. פאנל ניהול (Admin Web) — React + MUI
index.html + src/main.jsx: אתחול אפליקציית הניהול מבוססת Vite וטעינת רכיבי Material UI.

src/App.jsx: שלד המערכת, סרגל עליון, מעבר בין לשוניות ושמירת הסשן המנהלי.

src/theme.js: התאמת הצבעים של פאנל הניהול לשפה העיצובית של אפליקציית המובייל.

src/Services/api.js: לקוח HTTP שמצרף אוטומטית את הטוקן וחוסם גישה למשתמשים שאינם מנהלים.

src/Components/LoginPage.jsx: מסך כניסה מאובטח למנהלי מערכת בלבד.

src/Components/Analytics.jsx: דאשבורד סטטיסטי הכולל התפלגות תקלות, גרפים יומיים ומדדי פעילות.

src/Components/Dashboard.jsx: טבלה לעריכה, הוספה ומחיקה של תקלות מתוך המילון.

src/Components/UsersManager.jsx: ניהול רשימת המשתמשים, עדכון תפקידים וצפייה ברכבים המשויכים לכל משתמש.

4. חומרה וקושחה (Firmware) — ESP32
CarStats.ESP32.ino: התוכנה שצרובה על לוח ה-ESP32; מתחברת לנקודת הגישה בטלפון עם IP קבוע, מתחברת לפרוטוקול CAN bus/TWAI של הרכב, קוראת נתוני מנוע בזמן אמת (סל"ד, מהירות, טמפרטורה, מפלס דלק) וקודי תקלה, ומגישה אותם בפורמט JSON דרך שרת פנימי (כולל מצב סימולציה כשאין רכב מחובר).

platformio.ini: קובץ הקונפיגורציה לסביבת הפיתוח והצריבה של המיקרו-בקר.

5. קובצי שורש, אוטומציה ותיעוד (Root)
start-demo.bat: סקריפט להפעלה מהירה של אימולטור האנדרואיד עם קיבוע מיקום (GPS) מקומי לביצוע הדגמות.

gps-feed.bat: הזנה רציפה של נתוני מיקום לאימולטור לצורך בדיקת מציאת מוסכים ומסלולים.

netlify.toml: הגדרות פריסה אוטומטית (CI/CD) עבור פאנל הניהול בווב בעת ביצוע Push ל-Git.

.gitignore: קובץ אבטחה קריטי שמונע העלאת סיסמאות, מפתחות API וקובצי הגדרות רגישים ל-GitHub.

README.md / CLAUDE.md: תיעוד הפרויקט, הוראות הרצה, ארכיטקטורה והסברים טכניים למפתחים.
